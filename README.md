# Mouse Brain Surgery Planner

An early scientific desktop application for transparent and reproducible mouse
stereotaxic planning. Phase 1 provides a BrainGlobe-backed atlas browser, linked
orthogonal slices, 3D atlas geometry, explicit atlas coordinates, and versioned
project save/load.

> **Research-use warning:** This software is a planning and visualization tool,
> not a certified surgical navigation or medical device. Atlas coordinates are
> population-reference coordinates and must be independently verified before use.

See `INSTALL.md`, `USER_GUIDE.md`, and `SCIENTIFIC_VALIDATION.md` before using the
application.
